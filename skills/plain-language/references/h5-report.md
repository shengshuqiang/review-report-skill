# H5 报告规范

生成 H5 说明页时读取本文件。目标是让非研发读者先看懂结论，再能沿证据编号核验，不是制作装饰性网页。

## 页面顺序

1. **标题区**：报告标题、范围、更新时间、总体确认状态。
2. **结论区**：一句话结论、影响对象、对应证据编号。
3. **问题区**：每个问题一张卡片，按“用户表现 → 影响 → 复现 → 实际/预期 → 原因 → 确认状态”排列。
4. **证据区**：按 `E1`、`E2` 顺序展示代码、日志、数据或图片，并说明“此证据支持哪条判断”。
5. **建议区**：修复、验证或待补证据，说明责任边界。

不要先堆代码再让读者自行推导结论。一个问题引用多个证据时，在问题卡片列出全部证据编号；一个证据支持多个问题时分别说明支持范围。

## 代码标注

- 显示仓库相对路径或明确来源路径和真实行号范围。
- HTML 转义代码中的 `&`、`<`、`>`、引号，禁止把源码当 HTML 注入。
- 关键行使用 `.is-focus`，并放置与解释列表一致的数字标记；普通上下文保持低对比度。
- 只截取理解证据所需的上下文，默认关键行上下各 2–5 行。省略内容时用明确的省略标记，不伪造连续行号。
- 解释应写“这几行证明了什么”，不要只复述方法名。

示意结构：

```html
<div class="code-frame" aria-label="代码证据 E1">
  <div class="code-head"><code>src/example.ts:41-45</code><span>E1 · 代码实锤</span></div>
  <pre><code>
<span class="code-line"><span class="line-no">41</span><span class="line-code">const before = value;</span></span>
<span class="code-line is-focus"><span class="marker">1</span><span class="line-no">42</span><span class="line-code">submit(value);</span></span>
  </code></pre>
</div>
```

## 图片圈选

- 使用原始截图或用户提供图片，不重绘成看似真实的界面。
- 在图片容器上叠加与原图同一坐标系的 SVG。设置 `viewBox="0 0 原图宽 原图高"` 和 `preserveAspectRatio="xMidYMid meet"`，保证缩放后仍对齐。
- 使用椭圆或圆角框圈选区域，箭头指向触发点，数字标记与图片下方解释对应。
- 描边宽度按原图尺寸设置，避免缩放后过粗；圈选不覆盖文字或按钮本身。
- 无法确认坐标时不要猜测。先读取图片尺寸并查看原图，再标注。

示意结构：

```html
<div class="image-stage">
  <img src="data:image/png;base64,..." alt="真实页面截图，保存按钮区域已标注">
  <svg class="annotation-layer" viewBox="0 0 1170 2532" preserveAspectRatio="xMidYMid meet" aria-hidden="true">
    <ellipse class="annotation-shape" cx="965" cy="2290" rx="115" ry="70" />
    <g class="annotation-pin" transform="translate(850 2190)">
      <circle r="28" />
      <text text-anchor="middle" dy="0.35em">1</text>
    </g>
  </svg>
</div>
```

## 证据状态

- **运行实锤**：真实设备、页面、日志或数据已观察到目标现象。
- **代码实锤**：代码能直接证明机制或缺少保护，但不等同于设备已经复现。
- **代码推演**：依据静态路径推导可能表现，必须标注运行态未验证。
- **待确认**：关键输入、环境、频率或结果缺失，不能下确定结论。

每个状态都写清时间或代码基线。截图只能证明截图呈现的那个时刻；一次日志不能证明稳定复现。

## 视觉与可访问性

- 优先单列阅读，宽屏证据区可双栏；窄屏回到单列。
- 正文最小字号 15px，代码允许横向滚动，页面本身不得横向溢出。
- 结论、风险和待确认使用不同文字标签；颜色只是辅助，不是唯一信号。
- 图片必须有 `alt`，标记说明必须在图片外以文字再写一次。
- 不使用外部 CDN、追踪脚本或自动发送网络请求。

## 完成标准

- 页面离线打开无空白模块、断图和模板占位符。
- 每条结论都能通过证据编号追溯；每个圈选或代码编号都有文字解释。
- 原图与标注在桌面和窄屏缩放后仍对齐。
- 页面未泄漏密钥、账号、设备标识或其他敏感信息。
